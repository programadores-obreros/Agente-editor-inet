🔑 Tu API key de Google
Gratis, sin tarjeta, 2 minutos — es lo único que Tecnia Bot no puede resolver solo.

1 ¿Por qué hace falta?

Tecnia Bot usa Google Gemini para pensar y responderte. Google lo deja usar gratis, pero necesita saber quién sos — para eso existe la API key: un código que identifica tu cuenta, no una contraseña que escribís cada vez.

No es lo mismo que tu clave de Gmail. Es un código nuevo, específico para esto, que podés borrar cuando quieras sin tocar tu cuenta de Google.

2 Conseguila

  1. Entrá a aistudio.google.com/apikey con cualquier cuenta de Google.
  2. Tocá "Create API key".
  3. Elegí "Create key in new project" si te lo pregunta — así queda con su propia cuota, sin compartir nada con nadie.
  4. Copiá el código que te muestra.
🔑 Conseguir mi API key gratis →

3 Ponela en Tecnia Bot

Si estás instalando por primera vez: el instalador te la pide solo, al final. La pegás ahí y listo.

Si Tecnia Bot ya está instalado: abrilo, escribí /connect, buscá Google en la lista, y pegá tu key cuando te la pida.

Es un paso único: se guarda en tu compu y no se vuelve a pedir en las próximas actualizaciones.

4 Si algo no anda

La key guardada no es válida — puede que nunca se puso una de verdad, o que la que había dejó de funcionar. Conseguí la tuya (paso 2 de arriba) y ponela con /connect — pisa la anterior sin tocar nada más de tu instalación.

Ya había una key guardada de una instalación anterior (aunque esté rota, el instalador no lo sabe, así que no vuelve a preguntar). Usá /connect para poner la tuya — no hace falta reinstalar nada.

Se llegó al límite de uso por minuto de tu key (normal con pedidos grandes o si varios la usan a la vez). Esperá un minuto y probá de nuevo — se destraba solo. Si pasa seguido, es señal de que cada persona/aula debería tener su propia key en vez de compartir una.

💡 Por qué cada escuela necesita la suya: la cuota gratis de Google está atada al proyecto detrás de tu key, no a la persona. Si muchos comparten la misma key, comparten la misma cuota — y con un aula activa se agota rápido, para todos a la vez. Con tu propia key (gratis, 2 minutos), tu cuota queda aislada.
